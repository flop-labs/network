### Added

- `flop --network testnet agent credential`, `flop --network testnet launch claude|codex` and
  `flop --network testnet session run --new-wallet` run on Testnet. Wallet enrollment accepts only
  the selected network's gateway statement (`FLOP testnet gateway key`, `flop-testnet-enroll`)
  and, on Testnet, refuses an RPC that does not report the pinned genesis before creating or
  funding an account. Testnet funds a new account through the signed agent claim, not Devnet's
  `/fund`, and keeps its own key cache and enrollment account
  (`~/.flop/testnet-wallet-agent-key.json`, `~/.flop/testnet-enroll-wallet.json`).
- `session run --max-duration <seconds>` sets the force-open channel lifetime (the SDK's
  `maxDurationSeconds`). A miner whose close and evidence publication outlast the channel
  lifetime failed every settlement with `AttestationStale`; a longer lifetime gives it room to
  settle.

### Changed

- Breaking for scripts that parse the output: `model list` and `model get` report the registry
  account under the key `publisher` instead of `provider`, in every output mode (`--json`, agent
  and the default view). That account published the model. It is not a miner, and a session that names it can never
  be acknowledged. Read `publisher` where you read `provider`.
- Takes `@flop-labs/sdk` 0.13.0, which carries the 1200 s direct-session default, the
  `maxDurationSeconds` offer check and the calibration refusal below.
- `session run` channels default to 1200 s (the SDK default, up from 120 s): a Testnet worker's
  close (DA publication of the TOPLOC activations and transcript, evidence, then settle) took
  about 4.5 minutes, so a 120 s channel failed settlement with `AttestationStale`. 1200 s matches
  the standing offers (#4565) and Hermes direct (#3870).
- `session run --max-duration` no longer requires `--via force`. With `--via auto|offer` a signed
  offer is taken only when it grants at least that lifetime; otherwise auto force-opens with it.
- `flop agent init` and `flop agent doctor` in remote mode refuse on Testnet and Mainnet without
  `--mcp-url`, because neither publishes a hosted MCP server; they no longer write Devnet's MCP URL.
- A gateway that answers the enrollment challenge with 404 is reported as having wallet enrollment
  switched off.

### Fixed

- `session run --max-flop` help now calls the value the channel escrow, which cooperative close
  pays the miner in full. "Maximum escrow" read as a spending cap, so callers sized it far above
  the turn tariff and paid all of it.
- `session run` and `hermes direct` take the SDK's calibration check, so they refuse to force-open
  a channel against an account with no active calibration.
