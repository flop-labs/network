### Added

- `flop hermes plugin install` and `flop hermes auth`, previously only in the standalone
  `@flop-labs/hermes-launcher`. The public Hermes provider (`flop-public`) ships inside the
  CLI with its source revision and file pins, so the native Hermes setup works from the npm
  package. Both serve the public devnet gateway only: they need no `--network`, and an
  explicit other network or RPC is refused.
- `flop --network devnet hermes desktop --doctor` (read-only readiness check) and
  `--configure-only` (authenticate and save the isolated profile without launching), as in the
  launcher. Outside the public devnet route both are refused.

### Changed

- Use the dedicated Devnet faucet for CLI and hosted Hermes funding. Testnet faucet requests
  require the signed D10 RPC genesis, including when both endpoints are overridden.

### Fixed

- `--rpc-timeout <ms>` sets the RPC connect bound for every command (also
  `FLOP_RPC_TIMEOUT_MS`; default 10 s, retries included). `flop --network testnet network
  status` reports the Testnet genesis pin and `matches_expected` true or false.
- Commands that need a gateway fail with "no gateway is published for network testnet"
  (pass `--gateway` / `--catalog-base-url`) instead of dialing a host that does not resolve.
- `session create`, `wallet agent create` and `launch pi` parse `--daily-cap` and `--tx-limit`, and
  `proxy`, `chat` and `hermes desktop` parse `--max-flop`, as exact decimals with at most 18
  fractional digits. Input such as `1,000`, `0,5`, `5abc`, `0x10`, `-1` or `abc` is now rejected
  with a named error before connecting, instead of being truncated by `parseFloat`, and `4.35`
  is sent as exactly 4.35 FLOP (flop-labs/network#1170).
- `flop proxy`, `flop chat` and the Hermes embedded proxy keep serving past 50 requests: their
  local daily budget (50 × `--max-flop`, now stated in `--help`) resets every 86,400 blocks
  (flop-labs/network#1175).
