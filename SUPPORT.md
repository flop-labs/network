# Support

- **Questions** — ask in [Discussions → Q&A](https://github.com/flop-labs/network/discussions/categories/q-a).
  Issues are for actionable reports; a question opened as an issue will be moved there.
- **Ideas you want to talk through** — [Discussions → Ideas](https://github.com/flop-labs/network/discussions/categories/ideas).
  Once it is concrete, open a [feature request](https://github.com/flop-labs/network/issues/new?template=feature.yml).
- **Running a miner or validator** — start at [flop.finance/testnet](https://flop.finance/testnet/);
  [ask.flop.finance](https://ask.flop.finance) answers most setup questions from the docs.
- **Something broken** — open an [issue](https://github.com/flop-labs/network/issues/new/choose)
  with the matching form.
- **Security** — never in public. See [SECURITY.md](SECURITY.md).

There is no paid support and no response-time guarantee for questions.
